## Cài đặt cơ sở dữ liệu
Import `ql_anvat.sql` vào MySQL/MariaDB trước khi chạy website. Cấu hình kết nối của cả khu vực khách hàng và quản trị đều sử dụng database `ql_anvat`.

## 📂 Cấu Trúc Thư Mục
```bash
├── Admin/          # Giao diện quản trị viên
├── Images/         # Tài nguyên hình ảnh sản phẩm
├── KhachHang/      # Giao diện người dùng mua hàng
├── ql_anvat.sql    # Database dự án
└── README.md       # Tài liệu hướng dẫn
```
